01 — Background

專案背景

The Brief

智遊旅程希望加速旅行社業者的數位轉型，打造一套專屬於旅遊團的行動應用程式，讓導遊與旅客擺脫對 LINE 群組和實體導覽機的依賴，在旅遊前、中、後提供完整的數位服務。

My Role

擔任唯一 UI 設計師，獨立負責 APP 從視覺風格定義、設計系統建立、到 30+ 畫面完整交付。同時參與 UX 需求分析與產品測試，與 PM 及前後端工程師協作確保設計落地。

02 — Problem

使用者痛點

導遊

資訊分散，管理吃力

需要同時透過 LINE 群組管理行程通知、集合確認、旅客名單，訊息容易被洗版，緊急狀況難以即時處理。

旅客

找不到人，跟不上行程

不知道導遊在哪裡、集合地點要翻訊息才找得到、每次出遊都要重新加群組，資訊不集中造成焦慮。

旅行社

缺乏標準化工具

行前提醒、行程資訊、緊急聯絡各自為政，服務品質難以標準化，業者無法有效管理多個旅遊團。

現有工具的缺陷

導覽機笨重，LINE 不夠用

導覽機只有單向廣播功能、硬體成本高；LINE 群組缺乏旅遊專屬功能，無法整合定位與行程管理。

03 — Solution

四大核心功能

功能 01

上車事項

行前提醒與攜帶物品清單，讓旅客出發前掌握所有必要資訊，減少「忘記帶東西」的問題。

設計決策 → 放在首頁最顯眼位置，因為旅遊前的準備是最高頻的焦慮來源。

功能 02

集合定位

即時顯示導遊位置與集合倒數計時，解決旅客「找不到導遊」這個最高頻的痛點。

設計決策 → 地圖畫面刻意簡化，只保留導遊位置與集合點，降低戶外使用時的認知負擔。

功能 03

即時通訊

取代 LINE 群組的旅遊專屬通訊頻道，導遊可以發布集合通知、緊急公告，訊息不會被洗版。

設計決策 → 通知類型做視覺區分，讓旅客一眼判斷重要程度，不需要閱讀全文。

功能 04

更多功能

旅客名單、行程總覽、公告欄等輔助資訊集中管理，旅行社業者可依需求自訂內容。

設計決策 → 次要功能統一收在此區，避免主畫面資訊過載，維持介面清爽。

04 — Design System

視覺設計系統

主色 #FFD465 — 明亮黃色系傳達旅遊的活潑感與品牌識別。黃色在戶外日光下辨識度高，符合旅途中使用的場景。

字體 Noto Sans TC — 確保中文在各種裝置上的清晰度，Medium / Bold 兩種字重搭配，建立清楚的資訊層級。

整體介面原則 — 以簡潔為主，減少不必要的裝飾元素，讓導遊在戶外、行進間也能快速完成操作。

實際採用
這個專案讓我第一次獨立負責一個從零到上架的產品 UI。最大的挑戰是在快速開發節奏下同時維持設計品質與工程可行性。 透過與 PM 及工程師的密切協作，學會了如何在設計決策中考慮實作成本，以及如何在有限時間內做出取捨。

如果重來一次，我會在初期進行更多使用者訪談，尤其是針對導遊的實際使用情境，讓功能優先序的決策更有依據。
