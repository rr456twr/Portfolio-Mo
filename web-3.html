01 — Background

專案背景

The Problem

台灣市集文化蓬勃，卻缺乏統一的資訊平台。想擺攤的人要花大量時間 follow 各個市集的 Instagram 或 Facebook，往往錯過報名時間；主辦方則要手動處理大量報名訊息，效率低落。

Our Solution

打造一個市集媒合平台 SETALL，讓攤主可以集中瀏覽、收藏、報名市集，並即時掌握錄取狀態；讓主辦方能夠一站式管理報名、公告資訊、與攤主溝通。

02 — User Research

使用者研究

Persona 01

「厭倦目前的工作，嚮往著自己創業，但先以兼職擺攤作為開始的新手攤主」

痛點

  • 不清楚哪裡有市集
  • 不清楚需要什麼資料
  • 不清楚擺攤位置
  • 擔桌尺寸與想像不符
  • 無法即時得知錄取狀態

目標

  • 希望能即時掌握報名進度
  • 希望能了解下個月附近的市集資訊
  • 掌握準確地圖位置
Persona 02

「從幕後的市集主辦到幕前的市集攤主，不論是經營品牌或是攤攤事務都瞭如指掌」

痛點

  • 需要攜帶 29吋行李
  • 常因為鄰攤商品雷同影響銷售
  • 希望事先了解鄰攤資訊

目標

  • 事先了解左右攤位資訊
  • 一站掌握品牌宣傳管道
  • 提前規劃交通和住宿

03 — User Journey

使用者旅程

Key Insight

「等待錄取／備貨」是整個旅程中體驗最低的階段——攤主報名後完全不知道自己是否錄取、主辦方也可能沒有主動通知。

我們的設計回應：在攤主個人頁面加入「我的行程」功能，以即時狀態標籤（已錄取／審核中／未錄取／待報名）讓攤主不需要主動追問，隨時掌握每一筆報名的進度。

05 — Design Decisions

設計決策

決策 01

品牌識別與 LOGO

SETALL 的命名來自「Set All」——為所有人設置、媒合所有人。LOGO 設計以手寫感英文字體呈現品牌的親和力，並加入細微的市集意象，傳達平台輕鬆、社群感的調性。

決策 02

色彩系統

主色選用深森林綠，傳達市集戶外、自然、有機的氣息，同時展現平台的專業與可信度。米白色搭配淺綠作為輔助色，讓頁面保持清爽易讀。

決策 03

雙用戶角色設計

平台同時服務攤主與主辦方兩種截然不同的用戶。設計上以同一套視覺語言，透過不同的導航入口（「新手入門」分為攤商／主辦）區分兩種角色的使用流程，避免混淆。

決策 04

報名狀態透明化

針對 User Journey 中的最大痛點，設計「我的行程」功能，用視覺化狀態標籤讓攤主即時掌握每一筆報名的進度。綠色代表已錄取，灰階代表審核中或未錄取，一目了然。

正面肯定
這個專案是我第一次以主視覺設計師身份參與完整的 UX 設計流程——從 Persona、User Journey、Site Map 到高保真 UI 一氣呵成。最大的收穫是理解了「研究驅動設計」的意義：我的行程狀態功能不是憑空想出來的，而是直接回應了 User Journey 中找到的痛點。

如果重來一次，我會更早讓兩種用戶角色的流程並行設計，而不是先完成攤主側再補主辦方側，這樣可以更早發現兩者之間的介面一致性問題。
